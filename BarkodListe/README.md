# Barkodu Web — v0.1-beta

Scan barcodes with a camera or keyboard-style scanner, organize them by carrier, and export Excel or TXT lists. Repeated codes increase the quantity; leading zeroes are preserved.

Serve this directory over HTTPS to enable camera access. Camera and Excel libraries load from public CDNs. Lists remain in this browser. Real phone camera testing is pending.

For GitHub Pages, select this directory as the published site content, or copy `index.html` and `app.js` to a separate site's root. No product lookup is performed.
