# Barkod Listesi

Telefon kamerası veya klavye gibi çalışan barkod okuyucu ile barkod ekler. Tekrarlanan barkodların adedini artırır. Liste bu tarayıcıda saklanır ve gerçek `.xlsx` dosyası olarak indirilir. Barkodlar metin olarak aktarılır; baştaki sıfırlar korunur.

## GitHub Pages

1. GitHub'da bir depo oluşturun.
2. `index.html` ve `app.js` dosyalarını deponun ana klasörüne yükleyin.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Yayın adresini HTTPS üzerinden açıp kamera izni verin.

Kamera ve Excel kütüphaneleri internetten yüklenir. Gerçek kamera okuması telefon üzerinde denenmelidir. Ürün adı sorgulanmaz.
